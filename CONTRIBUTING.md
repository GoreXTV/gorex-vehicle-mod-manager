# Contributing

Thanks for helping improve GoreX Vehicle Mod Manager.

## Before opening a pull request

- Test your change in MTA:SA 1.6.0 r22470 or newer.
- Run the available Python tests.
- Run `tools/check_lua.ps1` on Windows when changing Lua code.
- Keep unrelated changes out of the same pull request.
- Update documentation for new commands, settings or workflows.

## Mod assets

Do not submit third-party `.dff`, `.txd`, `.col` or texture assets unless you have explicit permission to redistribute them.

When adding a mod with permission, preserve the original creator and license information in its metadata where possible.

## Bug reports

Include:

- MTA version
- Windows version
- VMM version
- category/mod involved
- exact reproduction steps
- relevant `debugscript 3` output
- screenshots or logs when useful
