# Changelog

All notable changes to the Vehicle Mod Manager will be documented here.

## [1.0.0] - 2026-09-30

### Added

- In-game vehicle mod library
- Infernus model switching
- Wheel replacement support
- Backlight texture replacement
- Search and category filtering
- Favorites and recent selections
- 3D vehicle preview
- Preview lighting modes
- Automatic preview snapshots
- Creator Mode with keyboard navigation
- Client-side asset caching
- Latent-event asset streaming
- Local/global permission separation
- Rescan and cache management commands
- Python import and asset validation tools
- Lua and Python development checks
